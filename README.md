# Superstore-Regional-Growth-Analysis
SQL and Excel data analysis project evaluating regional sales growth and the small-base effect.
Project Overview
The core objective of this project is to practice period-over-period comparisons by evaluating geographic performance shifts over time, identifying market acceleration trends, and checking for anomalies such as the small-base effect. 

Description: 
Compare region growth rates over a continuous timeline.  
Objective:
 Practice detailed period-over-period structural comparisons. 
Suggested Dataset: Global Superstore Sales Data. 
Analytical Rules: Enforce consistent periods across all calculations and explicitly screen for small-base effect distortions.

Technology Stack 
SQL Server Management Studio (SSMS): Utilized for dataset querying, yearly sales grouping, and window function handling (‘LAG()’). 
 Microsoft Excel: Utilized for data cleaning, dynamic pivot table transformation, error-handling formatting.
 Deliverable: 
Visualization Form: Multi-Line Trend Chart with Markers. 
Chart Title: Regional Growth Performance (2014-2017) 
X-Axis Layout: Continuous Fiscal Years (‘2014’, ‘2015’, ‘2016’,’2017’)
Y-Axis Layout: Growth Rate Percentage (‘%’)
